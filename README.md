## Menjalankan secara lokal
Unduh repository, lalu buka `index.html` menggunakan browser.

## Publikasikan menggunakan GitHub Pages
1. Buat repository GitHub bernama `dicka-portfolio`.
2. Unggah `index.html` dan `README.md` ke folder utama repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi. Alamat website akan tampil pada halaman Pages.
